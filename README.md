# ChatGPT Agent Test

A test repository to check whether ChatGPT can create and commit files directly through its GitHub integration.

## Demo: Ship It 🚀

A tiny, interactive task board created through a ChatGPT conversation.

**[View the source: index.html](./index.html)**

### Features

- Add, complete, and delete tasks.
- Filter by **All**, **Active**, or **Done**.
- Keep tasks in your browser using `localStorage`.
- Pure HTML, CSS, and JavaScript — no dependencies or build step.

### Run locally

Download or clone this repository and open `index.html` in a browser.

```bash
git clone https://github.com/mpsorokin/chatgpt-agent-test.git
cd chatgpt-agent-test
```

Then open `index.html` (for example, double-click it). GitHub Pages can also serve this file if enabled in repository settings.

## Experiment goals

- Create and update repository files from a ChatGPT conversation.
- Verify GitHub commits and permissions.
- Explore branches, pull requests, and code review.
- Compare the workflow with Codex.
